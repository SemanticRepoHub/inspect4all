# Contributing

We welcome well-scoped issues and pull requests. Discuss substantial changes in an issue first. Add tests to accompany source changes and describe how to reproduce the result. Build the native dependency with `make libenry`, use `uv sync`, then run relevant tests. Do not commit generated outputs, real keys, proprietary source, student data, or third-party test fixtures without appropriate rights and attribution. Preserve provenance and schema compatibility where feasible.
