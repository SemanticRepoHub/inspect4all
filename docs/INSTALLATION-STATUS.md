# Installation support status

Verified on **macOS Apple Silicon, 2 November 2026** from a fresh GitHub clone using `make libenry`, `uv tool install --force .`, and inspection of local d4py source (4.713 seconds in one run). Linux support is suggested by the Makefile, but not independently verified in this work. The native shared library must be built before packaging. This repository currently does not promise one-command Git URL installations.
